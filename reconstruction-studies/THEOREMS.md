# Manuscript-to-Lean index

The links point to the definitions and proofs. The repository records the [axioms of the declarations](verification/axioms.txt) separately from the experiments in the manuscripts.

## Ternary Measurements for Paired Local Recovery

| Manuscript statement | Lean declaration and scope |
| --- | --- |
| Theorem 1, binary degree zero | [exact_minimum_ranks](formal/TernaryCode.lean) proves exact rational and ternary optima using the physical recovery condition and the [receiver-order converse](formal/TernaryCodeLower.lean). [ColorAlphabetField](formal/ColorAlphabetField.lean) gives the field extension. |
| Theorem 1, binary degree $q-2$ | [paired_rank_lower](formal/AffineEdge.lean) and [binaryEncoder_attains](formal/AffineEdgeEncoder.lean) give the universal lower bound and a binary-valued attaining matrix over each field with $q$ distinct nonzero sites, including characteristic two. The construction specializes to rational ternary measurements. |
| Theorem 2 and the finite even/odd upper bounds | [theorem2_ternary_construction, theorem2_finite and theorem2_even_limit](formal/ColorAlphabetTheorem2.lean) give the finite bounds and fixed-even-alphabet limit. The same module quantifies the gap between the two certificates for odd alphabets. |
| Proposition 2.1 | [heterogeneous_receiver_order](formal/ReceiverOrderOptimal.lean) proves the optimum for unequal alphabet sizes. [ReceiverOrderGroupcast](formal/ReceiverOrderGroupcast.lean) identifies the maximum with the generalized independence number. |
| Lemma 3 | [selection_by_total_color](formal/ReleaseColor.lean) gives decoding for any sufficient translates in a finite abelian color group, the exact convolution count for the rank and preservation of ternarity. [ColorAlphabetTensor](formal/ColorAlphabetTensor.lean) supplies the physical decoder. |
| Lemma 4 | [paired_iff_polynomial_affine](formal/AffineEdgeDual.lean) proves both directions for the original polynomial matrix and affine tests. The same file constructs the polynomial matrix from solutions of the row systems. |
| Section 4.2, computing the polynomial matrix | [gaussian_reconstruction](formal/BareissPaper.lean) builds the integer row systems from the input labels, solves them by deterministic fraction-free elimination and writes every rational coefficient. Its bit-operation bound is polynomial in the physical array size, the number of slots and the input label width. [BareissSolverBounds](formal/BareissSolverBounds.lean) bounds operands by minors and proves exact divisibility. [AffineCostAudit](formal/AffineCostAudit.lean) verifies a second algorithm that directly generates the coefficients of this encoder. |
| Section 4.2, uniform rational construction | [decoder_correct and decoder_bit_complexity](formal/AffineCostAudit.lean) construct a valid polynomial matrix for the binary encoder and bound the bit steps by a polynomial in $D=4^q$, $q$, and the label bit width. The [compiler](formal/AffineCompile.lean) generates the coefficient tasks and expression trees. The [bit evaluator](formal/AffineCostExecute.lean) and [writer](formal/AffineCostOutput.lean) compute and encode the resulting rational coefficients. |
| Proposition 5 | [AffineEdgeOrbitZero](formal/AffineEdgeOrbitZero.lean) and [AffineEdgeOrbitBoundary](formal/AffineEdgeOrbitBoundary.lean) attain the orbitwise minima. [AffineEdgeOrbitResults](formal/AffineEdgeOrbitResults.lean) and [AffineEdgeOrbitCompare](formal/AffineEdgeOrbitCompare.lean) give strict comparisons and both limiting ratios. |
