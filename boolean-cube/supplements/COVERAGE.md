## Replaying the overlay

The release contains only Lean source, receipts, and replay/support files. It does not contain any OLEAN binaries. The pinned public baseline must have been built with Lean 4.28.0 and the Mathlib revision in its official manifest, `8f9d9cff6bd728b17a24e163c9402775d9e6a365`. This was verified on Windows. Point the replay at the baseline and installed 4.28.0 directory if different from its local defaults:

    .\replay.ps1 -Tag fresh -Baseline PATH_TO_BUILT_PUBLIC_CHECKOUT -Toolchain PATH_TO_LEAN_4_28 -Modules (Get-Content .\MODULES.txt)

The supplied receipts used empty output folders for the reported overlay phases. Reused public baseline dependencies were from the pinned release build, not rebuilt in this run; all 25 original source digests, the Lean binary version, the manifest pin, and the actual Mathlib HEAD were checked (HEAD in the latest witness replays). Module inputs were hashed before and after. Every reported new top-level proof was checked with `-j1 -DwarningAsError=true`; accepted axiom dependencies are only `propext`, `Classical.choice`, `Quot.sound`. The replay rejects missing named reports, new declared axioms, and placeholders. `CHECKS.json` is the phase inventory; `SOURCE_RELEASE.sha256` hashes every shipped file apart from the manifest itself.
